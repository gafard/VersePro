# Audio de répétition

Quatre phrases de l’exercice guidé, synthétisées localement avec la voix française Thomas à 130 mots par minute, puis converties en WAV mono PCM 16 bits à 16 kHz. Des silences séparent les phrases pour laisser le temps de lire et de valider. Aucun enregistrement de culte n’est inclus.

Ce fichier sert à découvrir le fonctionnement de la répétition ; ce n’est pas un corpus de validation d’accents, de microphones ou de salles.

Texte :

- Ouvrons Jean chapitre trois verset seize.
- Le rendez-vous de l’équipe est à dix-huit heures.
- Lisons le Psaume vingt-trois verset un.
- Terminons avec Romains chapitre huit verset vingt-huit.
